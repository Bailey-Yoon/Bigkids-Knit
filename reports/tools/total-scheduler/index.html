Total Scheduler

여러 종류의 엑셀을 타입별로 올려 한 군데에 취합하고, 날짜를 고르면 그 앞뒤 1~2주의 이슈를 모아 봅니다.
이 창에서는 저장이 안 됩니다. 올린 내용이 창을 닫으면 사라집니다 — 브라우저가 저장소를 막았습니다 (파일을 더블클릭해 file:// 로 열었거나, 시크릿 창이거나, 사이트 데이터가 차단된 경우). 게시된 주소로 열거나 폴더에서 python -m http.server 8791 을 띄운 뒤 http://127.0.0.1:8791/01_Published/index.html 로 여세요. 그 전까지는 둘러보기만 하시고, 「전체 내보내기」로 받아 두세요.

하루 범위

팀원 연차

날짜를 누르면 그날 연차와 그날 걸려 있는 다른 일정을 함께 보여줍니다 — 휴가를 잡기 전에 그날 무엇이 있는지 보려는 것입니다.

이 달 사용

1 · 무엇을 올리나요

① 종류 → ② 파일 → ③ 확인 → ④ 적재
엑셀을 끌어다 놓거나 눌러서 고르세요
.xlsx · .xls · .csv — 파일은 이 브라우저 안에서만 읽습니다. 어디에도 올라가지 않습니다.
같은 종류를 다시 올리면 키가 같은 줄만 갈아 끼웁니다. 파일에서 빠진 줄은 지우지 않습니다 — 일부만 발췌한 파일을 올렸을 때 나머지 일정이 통째로 사라지는 게 더 위험해서입니다.

2 · 읽은 내용 확인

2 · 시트와 머리글 줄

3 · 열 지정

날짜로 지정한 열이 각각 하나의 이슈가 됩니다 — 한 줄에 원단입고 / 투입 / 선적이 있으면 이슈 3개입니다. 키는 다시 올릴 때 같은 줄을 알아보는 기준입니다 (스타일 번호 · PO 번호 등).
엑셀 열샘플 값날짜로 읽으면역할이슈 이름 (날짜일 때)

한 건 직접 넣기

엑셀에 아직 없는 일정을 손으로 넣습니다. 지금 쓰는 양식 그대로 들어가므로 달력·목록에 똑같이 나옵니다.

손으로 넣은 것

타입

타입은 엑셀 양식 하나에 대응합니다. 열 지정(매핑)을 기억해 두므로 다음부터 같은 파일은 올리면 바로 들어갑니다.

업로드 이력

올릴 때마다 올리기 직전 상태를 남겨 둡니다. 고른 시점은 화면에만 올라오고, 「되돌리기 확정」을 눌러야 실제로 바뀝니다.

데이터 보관

지금은 이 브라우저에만 저장됩니다 (다른 사람·다른 기기에는 안 보입니다). 아래에서 JSON 으로 받아 두면 브라우저 데이터를 지워도 되살릴 수 있습니다.
팀 전체가 같이 보려면 Cloudflare Worker + KV 로 올려야 합니다 (fabric-request 와 같은 방식). 그 전에 바이어명 · 수량 · 단가가 사외로 나가도 되는지 판단이 필요합니다.
